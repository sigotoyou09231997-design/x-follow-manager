# Follow tidy リデザイン指示書

対象リポジトリ: `X フォロー整理ツール`（React 19 + Vite、状態管理は Dexie/IndexedDB、CSSはプレーンCSS）
参照デザイン: 添付モックアップ（スマホ版2枚 / PC版1枚）

## 0. 方針（重要・必読）

- これは**見た目（デザイン）だけの刷新**です。データモデル・保存先（IndexedDB / Dexie）・予約投稿のサーバー構成・非相互フォロー判定ロジックなど、**既存の機能は一切変更しません**。
- モックアップに写っている「今日のタスク（20人を確認する 残り8人）」「NOT FOLLOWING BACK 12/100 の1件ずつ確認カード」「5日前・1週間前…のタイムライン」は、**新しい保存項目を追加せず、既存データだけで表現します**（下記「3. 既存データとの対応」参照）。
- フォロー解除の操作（現状の「解除済みにする」ボタン）は新デザインの画像には写っていませんが、**必須機能なので画面下部に見えないボタンとして追加**します（「残す」「次へ」の下に配置）。
- 配色はモックアップに合わせて**ダークテーマを基準**にします。既存の `prefers-color-scheme` によるライト/ダーク自動切替の仕組みはそのまま活かし、ライト版のトークンもダーク版から逆算して作成してください（次章のトークン表を参照）。

## 2. 画面構成のマッピング（現状 → 新デザイン）

### 2-1. モバイル（幅 ~640px 未満、`src/App.tsx` のタブ構成を再編）

現状は上部固定タブ4つ（`一覧` / `作業モード` / `予約投稿` / `設定`）。モックの下部ナビ（5アイコン: ホーム／チェックリスト／＋／ベル／プロフィール）に合わせ、**下部固定ナビ（bottom tab bar）に変更**します。

| ボタン | 遷移先 | 対応する既存コンポーネント |
| --- | --- | --- |
| 🏠 ホーム | 新規「ホーム」画面（下記2-3） | 新規作成。中身は既存 `SummaryBar` の数値＋2つの入口カードを再構成 |
| ☑ フォロー整理 | 一覧＋確認フロー | `AccountListView` + `BatchWorkView` を統合した新しい画面（下記2-4） |
| ＋（中央の黒い丸FAB） | 「次の◯人を確認する」をワンタップで開始 | `BatchWorkView.selectNextBatch()` を呼び出し、確認カード（2-5）を開く |
| 🔔 予約投稿 | 予約投稿画面 | 既存 `ScheduleView`（アイコンは鐘ではなく `calendar` に差し替え推奨。理由は5章参照） |
| 👤 設定 | 設定画面 | 既存 `SettingsView` |

実装メモ:
- `App.tsx` の `type Tab` に `'home'` を追加。初期タブを `'home'` に変更（現状は `'list'`）。
- 下部ナビは `position: fixed; bottom: 0` とし、`--safe-bottom` を padding に含める（既存の `--safe-bottom` トークンを使用）。
- 中央の＋は他の4つより一回り大きい円形ボタンとして視覚的に浮かせる（`margin-top: -20px` 等）。

### 2-2. PC（幅 ~1024px 以上）

現状は上部タブのみ。モックはヘッダー＋左サイドバー＋中央リスト＋右ディテールパネルの3カラム構成に変更します。

- ヘッダー: 左にロゴ「Follow tidy」、中央に検索窓（`AccountListView` の検索input を移設）、右に「端末内で処理」バッジ（プライバシー説明の常時表示・既存フッターの文言を短縮して常設化）、右端にアバター（設定への導線）。
- 左サイドバー（固定・幅 220px 目安）:
  1. フォロー整理（一覧＋確認フロー、2-4）
  2. 残すリスト（`status === 'protected'` に固定フィルタした一覧。`AccountListView` の再利用でOK）
  3. 履歴（新規、下記2-6。`status === 'done'` を時系列表示）
  4. 予約投稿（既存 `ScheduleView`）※モック画像には写っていないが機能維持のため追加
  5. 設定（既存 `SettingsView`）
- 中央: リスト（2-4のリスト部分）
- 右: ディテールパネル（2-4の詳細部分）。中央リストで選択した1件を表示。

### 2-3. ホーム画面（新規）

モバイル1枚目相当。**新規画面ですが、表示するデータはすべて既存の `useSummary` / `AccountRecord` から算出**します。

- ヘッダー: 「Hey, tidy!」＋「気になる人だけ、残そう。」（固定コピー）、右上にアバター（設定への導線）
- 検索バー: タップで「フォロー整理」画面の検索欄にフォーカスして遷移
- 「フォロー整理」セクション: カード2枚
  - 「未確認 {pending}人 / 非相互フォローを整理」→ フォロー整理画面（未確認フィルタ）へ
  - 「残す {protected}人 / あとで見直す」→ 残すリスト（保護フィルタ）へ
- 「今日のタスク」セクション: チェックリスト2項目（**永続化しない、開いた時点の状態から動的に生成する疑似チェックリスト**）
  1. 「アーカイブを読み込む」: `hasData`（インポート済みか）で完了/未完了を判定。ラベルは「端末内で解析済み」固定。
  2. 「{batchSize}人を確認する」: 直近の作業バッチ（`useCurrentBatchKeys`）があればその進捗（`doneInBatch / batchAccounts.length`）を「残りX人」として表示。バッチが空なら「未確認{pending}人から次のバッチを始めましょう」的な導線ボタンにする。
  - ⚠️ 「1日の目標人数」を保存する新機能ではありません。あくまで直近バッチの進捗表示です。将来的に本当のデイリーノルマ機能が欲しい場合は別途要件化してください。

### 2-4. フォロー整理画面（一覧 + 確認フロー統合）

現状の `AccountListView`（一覧・フィルタ・CSV書き出し）と `BatchWorkView`（1件ずつのキーボード操作・フォーカス移動）を1画面に統合し、PC版はモックの「READY TO REVIEW」レイアウト（一覧＋右ディテールパネル）、モバイル版は一覧タップで詳細をフルスクリーン表示、に対応させます。

- 見出し: 小さいグレーのオーバーライン「READY TO REVIEW」＋大見出し「非相互フォロー{filtered.length}人」（`AccountListView` のフィルタ結果件数）
- フィルタタブ: `すべて / 未確認 / 残す` の3つに簡略化して表示（内部的には既存の `FILTERS`：`all / pending / protected` を使う。`done` タブは非表示にし、代わりに「履歴」画面に回す。CSV書き出しボタンは維持し、タブ列の右端 or リスト上部の設定アイコン内に格納）
- リスト行（PC中央カラム／モバイル一覧）: アバター（頭文字丸）＋名前＋`@ハンドル`＋経過時間（`account.updatedAt` or `importedAt` を相対時刻表示。既存にフィールドはあるので算出のみ追加）＋シェブロン。既存 `AccountRow` をこの見た目に置き換え、ボタン類は右のディテールパネル/フルスクリーン詳細側に移す。
- ディテールパネル（PC右カラム／モバイルはフルスクリーンカード。中身は `BatchWorkView` のフォーカス中アカウントと同じデータ）:
  - 上部ラベル「NOT FOLLOWING BACK」＋進捗「{currentIndex+1} / {batchAccounts.length}」（バッチ内の位置。全体件数ではなくモック同様バッチ内カウントでよい）
  - 大アバター、名前、`@ハンドル`
  - プロフィール文（bioは既存データに項目なし。無ければこのブロックごと非表示でよい。アーカイブから取得できるなら `NormalizedAccount` に追加を検討するが、今回は**スコープ外**）
  - ボタン3つ縦積み:
    1. 「残す」（bookmark アイコン）→ `onToggleProtect`
    2. 「次へ →」→ フォーカスを次のアカウントへ進める（`BatchWorkView.advanceFocus` 相当）
    3. 「解除済みにする」（モックには写っていないが必須。ボタン3にやや控えめなスタイルで配置）→ `onMarkDone`
  - 既存のキーボードショートカット（Enter/D/P/↑↓）はPC版で維持。ヒントテキストとして小さく表示。

### 2-5. 「今日」の1件確認カード（モバイル2枚目上部）

2-4のディテールパネルのモバイル専用表示です。日付ストリップ（週表示、当日ハイライト）は**装飾要素**とし、タップしても機能は変えなくてよい（将来「その日に確認した件数」を表示する拡張の余地として残す）。カード自体は2-4のディテールパネルと同一コンポーネントを使い回してください（重複実装しない）。

### 2-6. 履歴（新規画面／モバイルはホーム画面直下のタイムライン、PCはサイドバー「履歴」）

`status === 'done'`（解除済み）または `status === 'protected'`（残す）になったアカウントを、`completedAt` / `protectedAt`（両方とも既存フィールド）で降順ソートし、「◯日前」「◯週間前」の相対時刻付きタイムライン（縦線＋ドット）として表示します。

- 新しいDBフィールドは追加しません。
- 「プロダクトの観察とメモ」のようなメモ文言はモックの装飾例であり、対応するメモ入力欄は**現状データにないため実装しません**（アカウントの `displayName` やユーザー名を表示するに留める）。メモ機能が本当に必要な場合は別タスクとして切り出してください。
