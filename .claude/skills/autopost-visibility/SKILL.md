## これは何か

自分のブラウザには本人のログインがあるので、アカウントが制限されて**他の人には見えない**状態になっても、
自分の画面では普通に見えてしまう（2026-11-03 に Yay で実際に起きた）。
このスキルは、投稿先ごとに**ログインなし**で一覧や投稿を開き、本当に載っているかを確かめる。

確かめ方は `scripts/autopost-visibility.mjs` にまとめてある。手で組み立て直さず、これを走らせる。

## 手順

### 1. X（くり返し）の最新のツイートIDを取る（読むだけの SELECT）

ID は Supabase の `autopost_channels` にしか無い（RLS で鍵なしでは読めず、手元に service_role の鍵も無い）。
Chrome の Supabase SQL Editor（プロジェクト jqwclyzifihmwjnkrpkf）で次を流す。読むだけなので確認は要らない。

```sql
select status->>'lastId' as last_id, status->>'lastPost' as last_post, status->'problem' as problem,
       (select username from x_repeat_accounts limit 1) as acct
from autopost_channels where channel = 'xrepeat';
```

- エディタへの入れ方: `window.monaco.editor.getModels()[0].setValue("…")` → find で「Run」ボタン → クリック。
- 前の結果が下に残ったまま見えることがあるので、**結果が今回のものに変わったか**を見てから読む。
- `problem` が NULL でなければ、それも報告に入れる。`acct` は `lmpdtdgtd` のはず（本アカウントではない）。
- Chrome が使えないときは、この手順を飛ばして X は「確かめられない」と報告する（ほかの4つは確かめられる）。

### 2. スクリプトを走らせる（約15秒）

```bash
node scripts/autopost-visibility.mjs --x-id <1で取った last_id>
```

作業場所(worktree)から走らせても、投稿役のログは本体のフォルダ（Mac の投稿役が動いている所）から読む。
「見えない」「止まっている」が1つでもあると終了コードが 1 になる。

### 3. 報告する

投稿先ごとに「見える／見えない／確かめられない／止まっている」と、何で確かめたかを表で返す。
「気になる所」に出たものも書く。

## 投稿先ごとの確かめ方と、やってはいけないこと

| 投稿先 | 確かめ方 | 注意 |
|---|---|---|
| 掲示板（discord-ch.site） | まっさらなヘッドレスブラウザでトップの `article` 一覧から最後の文を探す | 一覧は画面側で組み立てるので curl では空。投稿役の自動の確認は `config.json` の `externalCheck: false` で切られている |
| えろぺ（eroype.net） | ログインなしで取ったトップのページに埋め込まれたデータ（createdAt）を読む | `article` は無い |
| Yay | 投稿役が毎回書いている「外から見えるか」のログを読む | **Yay の公開APIをここから叩かない**（2026-11-03 に手で連打して家の回線ごと 429 になり、同じ Wi-Fi のスマホまで使えなくなった） |
| X（くり返し） | ログインなしの埋め込み用の窓口（cdn.syndication.twimg.com の tweet-result）で、その ID が開けるか | **検索に出るか（検索から隠されていないか）は、ログインなしでは分からない**。それを正直に添える |
| ディス速 | ログの「ログインが切れています」だけ拾う | アプリの「投稿できていない表示」に未対応で、ここでしか気づけない（2026-11-26 に 11/17 から黙って止まっていた） |

## 見えない・止まっているときに、勝手にしないこと

- 投稿役の再開・間隔の変更・STOP の撤去・ログインの回避はしない。本人に伝えて判断を待つ。
- ログインのし直しは本人がやる（パスワードは扱わない）。どの窓で何にログインすればいいかだけ伝える。
- 確かめるために投稿役の `run.mjs` / `post.mjs` を手で起動しない（launchd の常駐と二重に動く）。
- 掲示板で「見えない」と出ても、流れが速くて押し出されただけのこともある。最後の投稿から何分たっているかと合わせて読み、
  続くようならもう一度走らせて確かめる。
