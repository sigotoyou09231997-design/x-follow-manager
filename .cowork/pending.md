# 取り込み済み・未実装のキュー

依頼を読んだら、**実装を始める前に**、その依頼に含まれる項目をここへ全部書き出す。
実際に動かして確認できたものだけ `[x]` にし、**やりきれなかった項目は消さずに残す。**
1回でやりきる必要はない（残しておけば次の実行が拾う）。

これが無いと、1つの依頼の中で「3項目のうち1項目だけ実装して依頼ごと実装済みにする」が起きて、
残りが静かに消える。依頼ファイル単位の記録（`state.tsv`）では、この途中状態は表せない。

書き方：

```markdown
## <依頼のファイル名>（取り込み: YYYY-MM-DD）
- [x] 実際に動かして確認できた項目
- [ ] まだ終わっていない項目
- [ ] 保留にした項目 — 理由（waiting.txt にも書く）
```

全部 `[x]` になったら、その節ごと消してよい（このファイル自体は残す）。
